# BRICK UI

This is a personal backport of **[nxredux](https://nxredux.com)** based on 1.13 with backports from later releases too.

There are custom backgrounds with the art of [Yumykon](https://www.instagram.com/yumykon/) included.
Thank you for giving permission to use your art in this project.

After installing the update the new backgrounds will be in the default Tools, Collections, "Recently Played" and ROM folders:
- Arcade (FBN)
- Game Boy Advance (MGBA)
- Neo Geo Pocket Color (NGPC)
- Ports (PORTS)

The extra Yumykon GBA and GBA Hacks backgrounds can be directly downloaded [here](https://github.com/bebeidon/nx-redux/releases/tag/artbook_custom_backgrounds) like the rest of the backgrounds too.
